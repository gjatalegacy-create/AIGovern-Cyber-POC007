# Public and private boundary

This Apache-2.0 release contains the historical POC007 source, fixtures, tests, documentation and selected disclosed evidence. It is self-contained: building it requires a Rust toolchain, not access to the company's runtime. Python is optional for the reference oracle.

The full **AIGovern-Cyber** integration remains locally retained as the company's separate commercial product. Its Light/Quantum/Shadow sources, binaries, state, operational transcripts and complete private evidence corpus are not included. This statement does not claim that a new private GitHub repository was created.

Public POC labels resemble production roles but do not instantiate their native authority or persistence boundaries. Private-system test counts and native verdicts must never be reported as tests of this smaller package. The separately disclosed R47 aggregate receipt and manuscript description are author-reported summaries; they do not include the private source or histories.
