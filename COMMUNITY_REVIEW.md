# Invitation to critical review

Bledar Gjata invites independent examination of the public AIGovern-Cyber POC007 reference and its ESS-MAI method. Test the claims, inspect the source and report what fails as carefully as what reproduces.

This invitation concerns the frozen [public bundle 0.1.2](https://github.com/gjatalegacy-create/AIGovern-Cyber-POC007/releases/tag/poc007-public-v0.1.2) and its disclosed scope. Current main-branch additions improve documentation and discovery; they do not constitute new runtime validation. The twelve public tests do not reproduce the separately reported private runtime.

## Submit a concrete review

- [Open a structured GitHub review](https://github.com/gjatalegacy-create/AIGovern-Cyber-POC007/issues/new?template=review.yml).
- [Discuss the matching public artifact on Hugging Face](https://huggingface.co/datasets/gjata-legacy/ess-mai-poc-007-aigovern-cyber/discussions).
- Read the [reproduction commands](REPRODUCIBILITY.md), [known limitations](KNOWN_LIMITATIONS.md), [review protocol](REVIEW_PROTOCOL.md), and [manuscript with full abstract and PDF](https://gjatalegacy-create.github.io/AIGovern-Cyber-POC007/paper/).

A useful report identifies the exact version or hash, environment, input, command, expected result, actual result and a minimal reproducer. Distinguish a code defect, a mismatch with the stated method, and a claim requiring evidence outside the public capsule. Criticism of the proposal and negative findings are welcome.

Review is voluntary. Downloading, using or discussing the code does not require identification, a review, or a favorable comment. The [Apache-2.0 license](LICENSE) governs the public code. A posted invitation, repository listing or citation does not establish that independent review has occurred.
