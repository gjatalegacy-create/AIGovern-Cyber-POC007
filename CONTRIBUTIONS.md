## Hardware adaptation

The proposal is to govern hardware execution by evidence and existing competence boundaries. Temperature, load, memory and energy estimates are distinguished from physical measurements. A computed estimate is not a sensor reading. A software acknowledgement is not proof of a physical effect. The private source includes model-based admission and response tests; the public capsule has no hardware-control implementation. There is no measured speedup, energy-saving or quantum-physics claim in this release. See the manuscript for the exact known limits, including the labelled CPU energy-estimate fallback.
