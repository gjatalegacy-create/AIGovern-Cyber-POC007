# Voluntary independent review

Anyone may reproduce, criticize or extend this POC. No institution, credential, fee, endorsement or review is required to use the Apache-2.0 material.

A useful report includes:

1. Exact Git commit or release, package manifest hash, OS/architecture and tool versions.
2. Commands, environment flags, complete outputs and whether tests were skipped.
3. Expected versus observed behavior, a minimal reproducer and any source changes.
4. Classification: reproduced result, counterexample, implementation defect, unsupported claim, or untested hypothesis.
5. Which claim and artifact are affected: this public capsule or a separately reported private experiment.

Please test missing positive/negative candidates, changed scope, trace mismatch and caller-constructed evidence. An expected failure is valuable evidence when its condition is explicit. Do not modify the outcome to obtain a desired PASS.

Submit findings through [GitHub Issues](https://github.com/gjatalegacy-create/AIGovern-Cyber-POC007/issues) or the Hugging Face repository's discussion facility. Avoid personal data, credentials and real production state.

Author responses and changes should preserve the original finding and identify superseding commits. Internal tests, AI-assisted review and anonymous comments are not labelled independent peer review. Reviewers decide whether to disclose their identity or affiliation.
